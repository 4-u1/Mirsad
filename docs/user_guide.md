# مِرصاد · دليل المستخدم المختصر

## التشغيل

```bash
pip install -r requirements-pipeline.txt
export MIRSAD_ADMIN_PASSWORD='…' MIRSAD_OPERATOR_PASSWORD='…' MIRSAD_VIEWER_PASSWORD='…'
python backend/load_db.py
uvicorn backend.app:app --port 8000
```
ثم افتح `http://localhost:8000`. إذا لم تضبط كلمات المرور، يولّدها `load_db.py` ويطبعها مرة واحدة.

بدون الخادم (مثل GitHub Pages) تعمل الواجهة في **وضع العرض**: الخريطة والشفافية كاملة، وقرارات الإنذار تُحفظ في متصفحك فقط.

## الحسابات

| الحساب | يقدر |
|---|---|
| مشاهد `viewer` | يشاهد الخريطة والإنذارات والشفافية |
| مشغّل `operator` | + يعتمد الإنذارات أو يرفضها |
| مسؤول `admin` | + يعدّل عتبات المستويات ويقرأ سجل التدقيق |

## الخريطة
- **الألوان:** كل قطاع ملوّن بمستواه، ومعه رمز ونص: ○ منخفض، ◆ متوسط، ▲ مرتفع، ■ حرج.
- **القطاع:** اضغط على القطاع أو على اسمه في قائمة «الأعلى خطرًا» لفتح التفاصيل: الدرجة، توزيع خلاياه، الارتفاع والانحدار والغطاء، والعوامل المؤثرة.
- **الطبقات:** من «مستويات الخطر» تشغّل خلايا 1 كم أو تطفيها، وكذلك الانهيارات التاريخية. الدائرة المعبّأة موقع دقيق، والمفرّغة موقع تقريبي.

## الإنذارات
1. يقترح النظام إنذارًا لكل قطاع بلغ «مرتفع» أو أعلى.
2. افتح «الإنذارات» وراجع الأسباب، واضغط «عرض» لرؤية القطاع على الخريطة.
3. اضغط «اعتماد» أو «رفض». يطلب النظام الدخول بحساب مشغّل.
4. يُسجَّل القرار باسمك ووقته. الإرسال للجهات **محاكى** في هذه المرحلة.
5. لا يُقبل اعتماد إنذار ثانٍ لنفس القطاع خلال 24 ساعة.

## الإعدادات (للمسؤول، عبر الـAPI)
```bash
curl -X PUT localhost:8000/api/v1/settings/thresholds -H "Authorization: Bearer <token>" \
     -H "Content-Type: application/json" -d '{"medium":0.4,"high":0.6,"critical":0.8}'
```
يعيد النظام تصنيف القطاعات، ويقترح إنذارات للقطاعات التي صارت «مرتفع» فأعلى، ويسجّل التغيير.

## اللغة والمظهر
- زر **EN / ع** يبدّل بين العربية والإنجليزية.
- زر **الشمس / القمر** يبدّل بين الوضع النهاري والليلي.
- يحفظ المتصفح اختيارك للمرة القادمة.

## قبل الاعتماد على الخريطة
اقرأ صفحة **الشفافية**. النموذج الحالي مدرّب على 12 نقطة انهيار فقط، وأداؤه في التحقق المكاني قريب من العشوائي. الخريطة أداة دعم قرار تجريبية، وليست بديلًا عن الدراسة الميدانية أو قرار الجهات الرسمية.
