# مِرصاد · دليل المستخدم

## الدخول إلى النظام

| | |
|---|---|
| الموقع | https://mirsad-rho.vercel.app |
| يعمل على | الجوال والكمبيوتر · عربي وإنجليزي · ليلي ونهاري |
| البيانات | قاعدة PostgreSQL + PostGIS على Supabase |

## الحسابات

| الحساب | اسم المستخدم | يقدر |
|---|---|---|
| زائر | بدون دخول | يشاهد الخريطة والإنذارات والشفافية والتقارير |
| مشغّل | `operator` | + يعتمد الإنذارات أو يرفضها |
| مسؤول | `admin` | + يعدّل عتبات المستويات ويقرأ سجل التدقيق |

كلمات المرور محفوظة في أسرار مستودع GitHub (`MIRSAD_OPERATOR_PASSWORD` و`MIRSAD_ADMIN_PASSWORD`) ولا تُكتب في أي ملف أو سجل. يعرفها قائد المشروع فقط.

## الخريطة

- **الألوان:** كل قطاع ملوّن بمستواه، ومعه رمز ونص: ○ منخفض، ◆ متوسط، ▲ مرتفع، ■ حرج.
- **القطاع:** اضغط على القطاع أو على اسمه في «الأعلى خطرًا» لفتح التفاصيل: الدرجة، توزيع خلاياه، الارتفاع والانحدار والغطاء، وأهم العوامل المؤثرة.
- **الطبقات:** خلايا 1 كم، والانهيارات التاريخية (الدائرة المعبّأة موقع دقيق، والمفرّغة تقريبي)، وتلوين القطاعات حسب الانحدار أو الارتفاع.
- **الخلفية:** «خريطة» أو «قمر صناعي» (Esri)، مع أسماء المدن.
- **Google Earth:** زر «عرض في Google Earth» في تفاصيل القطاع يفتحه على نفس المكان، وزر تنزيل ملف KMZ يحتوي كل القطاعات.

## تقرير القطاع

من تفاصيل أي قطاع اضغط «تقرير القطاع». التقرير فيه رقم مرجع، والدرجة على سلّم المستويات، والعوامل، وحالة الإنذار. إذا اعتُمد إنذار القطاع يظهر **ختم الاعتماد** باسم المعتمِد وتاريخه. يُطبع أو يُحفظ PDF من زر «طباعة».

## الإنذارات

1. يقترح النظام إنذارًا لكل قطاع بلغ «مرتفع» أو أعلى.
2. افتح «الإنذارات» وراجع الأسباب، واضغط «عرض» لرؤية القطاع على الخريطة.
3. اضغط «اعتماد» أو «رفض»، وادخل بحساب المشغّل.
4. يُسجَّل القرار باسمك ووقته في سجل التدقيق. الإرسال للجهات **محاكى** في هذه المرحلة.
5. لا يُقبل اعتماد إنذار ثانٍ لنفس القطاع خلال 24 ساعة.

## الإعدادات (للمسؤول)

```bash
curl -X PUT https://mirsad-rho.vercel.app/api/v1/settings/thresholds \
     -H "Authorization: Bearer <token>" -H "Content-Type: application/json" \
     -d '{"medium":0.4,"high":0.6,"critical":0.8}'
```
يعيد النظام تصنيف القطاعات، ويقترح إنذارات للقطاعات التي صارت «مرتفع» فأعلى، ويسجّل التغيير.

## التشغيل المحلي (للمطورين)

```bash
pip install -r requirements-pipeline.txt
export MIRSAD_ADMIN_PASSWORD='…' MIRSAD_OPERATOR_PASSWORD='…'
python pipeline/run_all.py
uvicorn backend.app:app --port 8000      # http://localhost:8000
```
بدون `DATABASE_URL` يعمل الخادم على SQLite محليًا. وبدون خادم يعمل مجلد `web/` وحده في **وضع العرض**، وقرارات الإنذار تُحفظ في المتصفح فقط.

## قبل الاعتماد على الخريطة

اقرأ صفحة **الشفافية**. النموذج الحالي مدرّب على 12 نقطة انهيار فقط، وأداؤه في التحقق المكاني ROC-AUC = 0.545. الخريطة أداة دعم قرار أكاديمية، وليست بديلًا عن الدراسة الميدانية أو قرار الجهات الرسمية.
